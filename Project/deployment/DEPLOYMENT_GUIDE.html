How to Deploy Your DBSE Project (Step-by-Step)

All deployment configurations have been created in the isolated deployment/ directory. Your original project files in backend/, mock-api/, and frontend/ are 100% untouched and safe.

Method 1: Free 5-Minute Cloud Deploy (Vercel + Render)
Recommended for University Demos

This gives you a real live public HTTPS URL (e.g., https://dbse-project.vercel.app) that you and your professors can open on any phone, laptop, or projector.

Step 1: Deploy Backend to Render (Free)
  1. Push your project repository to GitHub.
  2. Log in to Render.com (free).
  3. Click New + → Web Service → Connect your GitHub repository.
  4. Fill in these 4 settings:
    • Root Directory: mock-api
    • Build Command: npm install
    • Start Command: node index.js
    • Instance Type: Free
  5. Click Deploy Web Service. In ~2 minutes, Render gives you a live backend URL like:
    https://dbse-backend.onrender.com
Step 2: Deploy Frontend to Vercel (Free)
  1. Log in to Vercel.com with GitHub.
  2. Click Add New... → Project → Select your DBSE project repository.
  3. Under Root Directory, click Edit and select: frontend.
  4. Under Environment Variables, add:
    • Name: VITE_API_URL
    • Value: https://your-render-backend-url.onrender.com
  5. Click Deploy. Vercel automatically builds and provides your live public app link!
Method 2: One-Command Container Deploy (Docker Compose)
CO6 Enterprise Evaluation

Spins up the complete multi-container stack: PostgreSQL 16 (with pgvector extension pre-compiled), Academic Backend API, and Nginx-powered React Frontend.

Run with Docker on Any Machine / Cloud VM:
# From the project root folder:
cd deployment
docker compose up --build

Once started:

  • Client Frontend: http://localhost (Port 80)
  • Backend API: http://localhost:3001
  • PostgreSQL + pgvector: localhost:5432
Files Created in deployment/
  • deployment/render.yaml — Blueprint configuration for 1-click Render backend deployment.
  • deployment/vercel.json — Vercel SPA routing and Vite rewrite configuration.
  • deployment/Dockerfile.frontend — Multi-stage Nginx container for the React client.
  • deployment/Dockerfile.backend — Node.js container for the Academic Knowledge service.
  • deployment/docker-compose.yml — Multi-service composition (Postgres with pgvector + Backend + Frontend).
  • deployment/DEPLOYMENT_GUIDE.html — This interactive guide.
